---------------------------------------------------
AI DIAGNOSTIC SYSTEM
---------------------------------------------------

IMPORTANT:
Frontend must NEVER call Gemini/OpenAI directly.

AI keys remain backend-only.

Create:
POST /api/v1/ai/diagnostics

Supports:
- multipart/form-data
- image upload
- text input

Flow:
1. Upload image using multer
2. Store in uploads/
3. Call Python FastAPI AI service
4. AI classifies:
   - category
   - subcategory
   - issue type
5. Backend maps AI output to Product DB
6. Return stable frontend-compatible response

Response format:
{
  "issue": "Wall Crack",
  "severity": "Medium",
  "recommendation": {
    "productId": "...",
    "name": "UltraTech Seal & Dry"
  },
  "reasoning": "AI-based explanation",
  "additionalProducts": [],
  "diagnosticId": "..."
}

If no product match:
1. Create SupportTicket
2. Save AIRequest
3. Return escalation response
